❌ Q4. How would you log malformed lines instead of skipping them?
Your answer
Not sure
Perfectly okay. This is where we learn.
🔍 What Google is testing here
Observability
Debuggability
Production thinking
✅ Simple, correct approach
Option 1: Print (basic)
print(f"Malformed line: {line}")
Good for small scripts, not production.
Option 2: Logging (Google-preferred)
import logging

logging.basicConfig(level=logging.WARNING)

try:
    value = int(line)
except ValueError:
    logging.warning(f"Malformed line skipped: {line}")
Why Google likes this
Doesn’t crash
Keeps record of bad data
Scales to production systems
⭐ Google-ready explanation
“Instead of skipping malformed lines silently, I would log them using a logging framework so we can debug data quality issues without interrupting processing.”
